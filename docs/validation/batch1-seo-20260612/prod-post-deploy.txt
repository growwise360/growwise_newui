## Production issue

`/sitemap.xml` serves the **homepage** instead of the sitemap index route.
Child sitemaps (`/sitemap-pages.xml`, `/sitemap-blogs.xml`) work correctly.
Likely cause: Next.js reserved `/sitemap.xml` path conflicts with `app/sitemap.xml/route.ts` on Vercel
(deleting `app/sitemap.ts` may leave the path unresolved → homepage fallback).

## Recommendation

Fix `/sitemap.xml` routing before GSC recrawl — restore `app/sitemap.ts` as MetadataRoute
or add a rewrite. All other Batch 1 SEO fixes are live on production.
