# GrowWise Page Jobs and JTBD Map

This map keeps each public page honest about its job. A page should not be only a topic; it should help a parent or student make progress toward a specific decision.

## Page Job Types

| Type | Primary job | Success behavior |
| --- | --- | --- |
| Traffic | Capture search, AI answer, or social discovery demand | Reader finds a useful answer and clicks to a related money or trust page |
| Trust | Reduce risk and build belief | Visitor believes GrowWise is credible, local, safe, and capable |
| Money | Convert high-intent demand | Visitor books an assessment, enrolls, contacts, or starts a trial |
| Utility | Complete an account, checkout, or form task | User finishes the task with minimal friction |

## Core JTBD Themes

| JTBD | Parent/student thought | Primary page types |
| --- | --- | --- |
| Diagnose the gap | "I need to know what is really wrong before I choose help." | Traffic, Money |
| Choose the right program | "I need to compare options without guessing." | Traffic, Money |
| Build confidence and independence | "I want my child to stop fighting schoolwork and start feeling capable." | Traffic, Trust, Money |
| Prepare for a transition | "My child is moving into a harder grade, course, or exam." | Traffic, Money |
| Build future-ready skills | "I want coding, AI, or technical skills to become real ability, not just screen time." | Traffic, Money |
| Trust the provider | "I need proof this school is safe, local, qualified, and worth my time." | Trust, Money |

## Content Rule for New Pages

Before a page is written, assign:

1. Page job: Traffic, Trust, Money, or Utility.
2. Primary JTBD: one sentence in the visitor's words.
3. Next action: the page it should naturally send the visitor to.
4. Proof needed: example, diagnostic, testimonial, schema, comparison, or local signal.

If a page cannot answer those four items, it should not ship as a standalone page.
